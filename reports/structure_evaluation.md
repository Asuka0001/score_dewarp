# 结构评测与谱线检测修复（2026-11-15）

本阶段完成统一的结构评测和最终输出检测修复，未重新训练网络。使用既有全量权重 `outputs/deepscores_finetune/full_ca_lr1e-3_s7/best.pt`。

## 评测补齐

新增 `scripts/evaluate_materials.py`，同时比较原图、传统 A+B+C、网络实际反演映射（不加 C）：

- 几何：AD、局部畸变、采样网格覆盖率；两种实际映射均检查画布边界及 2px 原图往返误差。
- 共同有效点：在两种校正方法有效点的交集上重新计算几何与结构指标，每种方法使用相同的支持点，避免裁切改变误差比较。
- 五线谱：谱线平直度、线距 CV、小节线倾角。
- 简谱：基线平直度、字高 CV、字符倾角、高低音点误差、歌词对齐误差、行距 CV。
- 缺失标注/有效点：未定义项留空，结构关键点覆盖率单独记录，不把缺失当成零误差。
- 检测质量：有谱线真值时，将五线谱表实例一对一匹配，统计 precision / recall、匹配/预测/真值实例数。谱种正确不等于所有谱表、区域和关键点都正确。
- 困难样本：列出几何误差最高、覆盖率最低、谱线/基线平直度最差的页面；可保存校正图、结构叠加图和导出 JSON。

DeepScores 当前转换数据没有谱线关键点真值，因此只报告几何与谱种输出，不能把该数据上的谱种一致率解释为谱线精度。

## 检测修复

1. 全局 Otsu 二值化受深色符头支配，会丢失模糊后较浅的谱线。无谱表时使用局部对比度掩码恢复水平线证据，保留原有文字/数字掩码。
2. 原分组只通过共享片段连接五线观测，符号把五条线同时截断时会导致整个谱表被宽度阈值丢弃。新增有间距、位置及最大间隔限制的分组连接，不在缺口中生成虚构线点。
3. 标题中的缺字方框被模板识别成连续数字 0。新增带内部孔洞的矩形轮廓检查，保留正常圆形 0 的识别。
4. 谱表区域边界包含曲线中间的极值，避免只看两端漏掉弯曲部分。

恢复的浅色线证据尚未校准优化权重，直接用于 B/C 拟合在试验中出现过几何退化。因此最终输出启用改进检测；B/C 继续使用原有观测规则（`robust=False`）。3 张验证素材与提交前检测器对照，B/C 的映射及校正图均逐像素一致，仅最终结构输出更新。具体记录见 `outputs/structure_validation_20261115/optimizer_regression.json`。

## 本阶段之后

- 在有标注的困难页面上继续减少谱表重复检测与漏检；DeepScores 仍需补充谱线真值，才能严格评估其关键点和区域精度。
- 需要置信度/残差约束后再研究把恢复的谱线送入 B/C，不能凭谱种检测变好就默认几何拟合也会变好。
- 结构指标与整页几何指标不等价；后续简谱/混排训练应同时检查两者，并保留覆盖率及共同有效点比较。
