# 文档矫正方法复核与谱线网格改造（2026-11-17）

本轮 CPMS 开发回归：结构网格方案的平直度中位数从传统 0.158 降至 0.123，下降约 22.4%，逐页 58/60 胜传统。这是固定检测谱线上的诊断收益，不是未见真实数据的识谱准确率结论。

运行入口已接入 CLI，但保留传统方案为无 checkpoint 时的默认：新残差虽然不裁切矩形画布，组合上游含 NaN 的映射时，有限域边缘仍可能损失有效像素；边缘墨迹代理指标也有退化。不以单项平直度收益自动替换默认。

## 原方案的问题

1. 当前网络在照片像素上自由预测二维正向 UV，再用页面掩码选点、Delaunay 散点插值反演。其结构约束只在训练时软惩罚，推理时没有利用当前照片的谱线证据；正向场中的局部异常会进入反演。
2. 实际第 120 轮：cons=0.00000375，乘权重 5 后仅占总损失约 **0.161%**。这是损失数值贡献，不等同于梯度贡献。选模为 EPE + 边界 EPE + 折叠率，没有直接选择谱线平直度。因此“加了结构损失”不能推断模型已充分学会谱线约束。
3. 正 Jacobian 仍允许不合理的拉伸/剪切；仅在左上角检查一次也可能漏掉另一个三角形的翻折。白页背景上的平均坐标误差不能替代音符与谱线的局部几何质量。
4. 水平谱线能强约束纵向展开，但不能单独确定横向真实长度。不能为了把线拉直而任意调整横向尺度；仍需相机/曲面、竖线或其他形状证据。

## 参考成熟方法与实际实现

- [RDGR / Grid Regularization (CVPR 2022)](https://openaccess.thecvf.com/content/CVPR2022/papers/Jiang_Revisiting_Document_Image_Dewarping_by_Grid_Regularization_CVPR_2022_paper.pdf)：借鉴显式行几何与弯曲能量共同求解网格；本项目将文本行先验换成五线谱整线水平、同谱表等距约束。不是论文复现。
- [UVDoc 官方实现](https://github.com/tanguymagne/UVDoc)：接入原作者 2D/3D 双任务预训练模型，使用直接 backward 控制网格；固定版本 `4c9b82b537057aff2526e6dd118a847cdd072e82`，Git blob 与 SHA-256 校验；MIT 许可随下载保存。没有在本项目重新训练它。
- [DocTr 官方推理](https://github.com/fh2019ustc/DocTr/blob/main/inference.py)、[DewarpNet 官方实现](https://github.com/cvlab-stonybrook/DewarpNet)：直接 backward map 与从原图采样是成熟路径。本次接入 UVDoc 进行实测，没有声称运行全部这些模型。

结构方案：保持 A/B 在原图相机坐标系的全局拟合，并保留 C 的横向尺度、竖线与字符约束，之后加入受约束的谱线网格。仅粗校正和最终结果均检测为 staff 时启用；简谱/混排或证据不确定时保留原 ABC。

网格拟合整条线的绝对目标，使用二阶弯曲正则与 Huber 重加权；纵向局部尺度限制为 0.5–2，纵向剪切上限 0.5，必要时缩小位移。X 保持不变，上下边界固定，按单调列反演，避免再次使用散点反演。不改善结构或损伤其他已检出谱表的解被拒绝。上述保证仅针对新残差，不能修复上游已发生的翻折。

CLI 另检查学习方案最终映射的四个 Jacobian 角；发现局部无效方向时回退结构方案，并在 JSON 明确记录。`--network-only` 保留未经回退的研究基线。下表评测原始各分支，不启用 CLI 回退，以免掩盖失败。

## 限制与后续

- 低维网格与显式线约束比自由坐标回归更符合该任务，但通用预训练模型也不保证适配乐谱；以本次实测为准。
- 残差网格不恢复被上游 B 裁掉的标题，也不能修复上游网络已有的横向形变或翻折。CLI 回退是拒绝不可靠候选，不是证明回退结果完全正确。
- 还需新的真实照片、人工点标注及 OMR 音高/时值错误率，尤其覆盖简谱与混排。后续若训练自有模型，应优先 backward 控制网格、按谱线尺度归一的结构误差，以及结构/局部畸变参与选模；不要沿原目标盲目增加轮数。
- 未改动旧权重、训练数据或当前完成的训练记录。
