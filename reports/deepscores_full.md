# 全量 DeepScores 训练：验证与测试

权重 `outputs/deepscores_finetune/full_ca_lr1e-3_s7/best.pt`：Doc3D 初始化，CoordConv + attention，384×512，LR 0.001，seed 7，train 2810 / val 172。
按全量 val 的 UV EPE 选模：初始 19.05% → 最佳 **0.54%**（第 53 轮，共 53 轮 / 18656 步，7.0 h，停止原因 early_stopping）。
对比的 pilot 模型 `outputs/deepscores_finetune/ft_ca_lr1e-3_s7/best.pt` 仅用 128 个训练样本，其余设置相同。

注意：最佳轮就是最后一轮。`min_delta=0.02` 是绝对阈值，EPE 降到约 0.55% 后每轮改进只有约 0.01，不再计为显著改进，因此在余弦学习率结束前触发早停（最后 6 轮 EPE：0.571, 0.563, 0.549, 0.552, 0.550, 0.536）。模型可能还没有完全收敛。

测试集只评测一次，模型和 C 的参数都已经按验证集固定，没有根据 test 结果做任何调整。
pilot val/test 与全量数据中对应页面的照片逐字节相同，各集合按曲谱分组划分，与全量 train 没有重叠。
